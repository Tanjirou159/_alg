# Midterm — Homework Project Index

課程：演算法　|　學生：溫禮安　|　學號：22

A complete index of the homework projects from HW 1 through HW 9, each with a one-line summary.

| Homework | Project | Description |
| -------- | ------- | ----------- |
| HW 1 | [SAT Solver via Truth Table](https://github.com/Tanjirou159/_alg/tree/main/HW%201) | Enumerates every truth assignment to decide Boolean satisfiability and prints the full truth table. |
| HW 2 | [Recurrence Equations](https://github.com/Tanjirou159/_alg/tree/main/HW2) | Derives exact closed forms and Big-O bounds for four recurrences, then verifies them with a step-by-step simulation. |
| HW 3 | [SAT Solver via Truth-Table Enumeration](https://github.com/Tanjirou159/_alg/tree/main/HW3) | Implements a truth-table SAT solver that safely evaluates formulas with Python's restricted `eval`. |
| HW 4 | [Iterative Methods](https://github.com/Tanjirou159/_alg/tree/main/HW4) | Solves `x³ − x − 2 = 0` with Newton-Raphson and provides a reusable framework with nine iteration demos. |
| HW 5 | [Functional & Recursive Programming](https://github.com/Tanjirou159/_alg/tree/main/HW5) | Builds loop-free bubble sort with recursive `map`/`filter`/`reduce`, recursive and stack-based Hanoi, and symbolic differentiation. |
| HW 6 | — | No HW 6 submission is present in this repository. |
| HW 7 | [C(n,k): Recursion vs. DP](https://github.com/Tanjirou159/_alg/tree/main/HW7) | Compares naive recursion with a rolling-array Pascal's-triangle DP for binomial coefficients, including benchmarks. |
| HW 8 | [TSP — Five Algorithms](https://github.com/Tanjirou159/_alg/tree/main/HW8) | Compares greedy, 2-opt, hill climbing, simulated annealing, and gradient descent on the traveling salesman problem. |
| HW 9 | [Search & Optimization Algorithms](https://github.com/Tanjirou159/_alg/tree/main/HW9) | Solves five exercises: maze DFS, river-crossing BFS, bitwise N-Queens, 8-direction A* pathfinding, and IC routing. |
